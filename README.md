# ソフトテニス ラケット作成シミュレーター

ソフトテニスのラケットを自作するための設計シミュレーターです。
素材・シャフト形状・重量・バランス・フェイス面積・フレーム厚・ストリングなどを選ぶと、
性能スコア、スイングウェイト、ポジション適性、材料費の目安、製作難易度と手順をその場で計算します。

Angular 22（Standalone Components / Signals / Zoneless）と TypeScript 6 で構築しています。

## 機能

- **設計フォーム**: スライダーとセレクトで 12 項目を調整。4 種類のプリセット（前衛・後衛・快適・自作入門）から開始できます。
- **SVG プレビュー**: フェイス寸法・シャフト本数・ストリングパターン・グリップサイズ・カラーを実寸比で描画し、全長とバランスポイントを図示します。
- **性能レーダーチャート**: パワー / コントロール / 操作性 / 面安定性 / 打球感 / スピン / 耐久性の 7 指標（0〜100）。
- **スペックシート**: ポジション適性（前衛・後衛・オールラウンド）、スイングウェイト、バランス分類、材料費の内訳、規定値との照合。
- **自作ガイド**: 素材ごとの製作手順と、設計値に応じたアドバイス、難易度と作業時間の目安。
- **保存と共有**: ブラウザ（localStorage）への保存、JSON の書き出し / 読み込み、URL ハッシュによる共有。

## 計算モデルについて

`src/app/services/racket-calculator.service.ts` に純粋関数としてまとめています。

- 各入力値を入力範囲で 0〜1 に正規化し、指標ごとの重み付き和でスコア化しています。重みは市販ラケットの傾向（軽量・トップライト・シングルシャフトは前衛向き、など）を基にした相対的な目安です。
- スイングウェイトは、ラケットを一様な棒とみなし、重心まわりの慣性モーメント `m·L²/12` に平行軸の定理で `m·d²` を加えた簡易モデルです（軸はグリップエンドから 10cm）。
- フェイス寸法は縦横比 1.3 の楕円で近似しています。
- 規定値（全長 700mm 以内など）は日本ソフトテニス連盟の用具規定を参考にした目安です。必ず最新の公式ルールブックをご確認ください。

## 開発

Node.js 24 LTS（22.22.3 以降でも可）が必要です。`.nvmrc` を置いてあるので、nvm をお使いの場合は `nvm use` で切り替えられます。

```bash
npm install
npm start          # http://localhost:4200/
npm test           # Vitest によるユニットテスト
npm run build      # dist/ に本番ビルド
```

## ディレクトリ構成

```
src/app/
├── models/racket.model.ts            設計値・性能プロファイルの型
├── data/racket-catalog.ts            素材・シャフト・ストリング等のカタログとプリセット
├── services/
│   ├── racket-calculator.service.ts  性能・費用・難易度の計算（純粋関数）
│   └── racket-design.store.ts        設計状態、保存、JSON / URL 共有
└── components/
    ├── design-form/                  入力フォーム
    ├── range-field/                  スライダー + 数値入力
    ├── racket-preview/               SVG プレビュー
    ├── performance-radar/            レーダーチャート
    ├── spec-sheet/                   スペックシート
    ├── build-guide/                  自作ガイド
    └── saved-designs/                保存・共有
```
